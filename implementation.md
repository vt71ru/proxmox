Implementation.md
План внедрения и приёмки инфраструктуры

Версия: 1.0
Статус: План работ
Платформа: Proxmox VE 9.0

1. Принципы внедрения
Не переустанавливать работающие системы.
Не менять адреса без необходимости.
Не удалять действующие правила Firewall до проверки.
Не менять VLAN активных портов без плана отката.
Не отключать существующие подключения Windows.
Перед каждым изменением сохранять исходную конфигурацию.
После каждого этапа проводить проверку.
Все административные учётные записи принадлежат владельцу.
2. Этап 1. Фиксация исходного состояния

Оценка: 30 минут.

Сохранить:

Конфигурацию Proxmox.
/etc/network/interfaces.
Конфигурацию VM и LXC.
Storage configuration.
Firewall configuration.
Конфигурацию маршрутизатора.
VLAN и PVID коммутатора.
Настройки точки доступа.
DHCP и DNS.

Результат: резервная копия действующей конфигурации.

3. Этап 2. Проверка маршрутизации

Оценка: 30 минут.

Проверить:

Windows Ethernet.
Windows Ethernet 2.
Основной и дополнительный шлюзы.
Маршрут до Proxmox.
Маршрут до VLAN 30.
Доступность NAS.
Отсутствие конфликтующих маршрутов.

Никаких изменений до фиксации исходной таблицы маршрутизации.

4. Этап 3. VLAN и коммутатор

Оценка: 45 минут.

Проверить:

VLAN 30.
Trunk до Proxmox.
VLAN-aware bridge.
Порты NAS.
Порты точки доступа.
Wi-Fi VLAN.
PVID.
Native VLAN.

Не создавать неподтверждённые VLAN 40–70 автоматически.

Результат: согласованная схема коммутации.

5. Этап 4. Firewall

Оценка: 45 минут.

Порядок:

Аудит текущих правил.
Проверка административного доступа.
Проверка разрешённых соединений.
Согласование межсетевого доступа.
Ограничение внешнего доступа.
Проверка обратных соединений.
Проверка гостевой изоляции.

Результат: документированная политика Firewall.

6. Этап 5. DNS и DHCP

Оценка: 30 минут.

Проверить:

DHCP для действующих сегментов.
Постоянные адреса серверов.
DNS.
Внутренние имена.
Отсутствие конфликтов IP.

Результат: стабильное разрешение имён и выдача адресов.

7. Этап 6. NAS

Оценка: 30 минут.

Проверить:

IP и шлюз.
Доступ с Windows.
SMB.
DLNA.
Права пользователей.
Резервное копирование.

Результат: доступное сетевое хранилище.

8. Этап 7. Мультимедиа

Оценка: 60 минут.

Настроить и проверить:

SSDP.
DLNA.
SSDP relay при необходимости.
mDNS reflector при необходимости.
IGMP snooping.
Wi-Fi multicast.
Доступ телефона.
Доступ телевизора.
Доступ TV Box.

Результат: работающая домашняя медиасеть.

9. Этап 8. Контроль безопасности

Оценка: 40 минут.

Проверить:

Пользователей Proxmox.
API tokens.
SSH-ключи.
VPN.
NAT.
Port Forwarding.
Удалённое управление.
Неизвестные службы.
Пользователей NAS.
Доступ из интернета.

Результат: документированный перечень разрешённых административных способов доступа.

10. Этап 9. Резервирование

Оценка: 40 минут.

Проверить:

Резервное копирование VM.
Резервное копирование LXC.
Данные NAS.
Конфигурации Proxmox.
Отдельную копию критически важных данных.
Возможность восстановления.

Результат: проверенная процедура восстановления.

11. Этап 10. Финальное тестирование

Оценка: 45 минут.

Windows	Доступ к разрешённым ресурсам
Nginx	Работает

Git	Работает

Телефон	Обнаруживает медиатеку
Smart TV	Воспроизводит видео

Firewall	Изоляция соблюдается
Backup	Создаётся и восстанавливается

13. План отката

Перед каждым этапом:

Сохранить исходную конфигурацию.
Записать изменяемые параметры.
Подготовить способ возврата.
Убедиться в наличии локального административного доступа.

При потере связности:

Не продолжать следующие изменения.
Восстановить последнюю рабочую конфигурацию.
Проверить управление Proxmox и маршрутизатором.
Повторить контрольные испытания.
14. Передача владельцу

Исполнитель обязан передать:

Все конфигурационные файлы.
Таблицу IP.
Таблицу VLAN.
Правила Firewall.
Таблицу маршрутизации.
Схему коммутации.
Перечень пользователей.
Перечень VPN и удалённых доступов.
Пароли и ключи.
Резервные копии.
Инструкцию восстановления.

Временные учётные записи исполнителя отзываются после приёмки.

15. Итоговый критерий завершения

Работа считается завершённой только после того, как:

Сеть работает.
Все согласованные устройства доступны.
Firewall соответствует утверждённой политике.
Телефон, телевизор и TV Box работают с NAS.
Неизвестные способы удалённого доступа отсутствуют.
Владелец получил все конфигурации и учётные данные.
Проверено резервное восстановление.
